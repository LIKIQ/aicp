# 内置表情包素材放这里

把表情图片按情绪分到子目录里，首次启动时会自动导入成对应的分组。

```
app/src/main/assets/stickers/
  开心/
    a.png
    b.jpg
  无语/
    c.png
```

## 规则

- **子目录名就是分组名，也就是这组图的情绪**。模型选表情时只看情绪，不看单张图叫什么，
  所以图片文件名随便起，`IMG_2049.png` 也没关系
- 情绪名请用词表里的词：开心、大笑、害羞、得意、撒娇、无语、尴尬、疑惑、思考、惊讶、
  伤心、哭、委屈、生气、无奈、困、累、可爱、点赞、比心
  （见 `domain/sticker/StickerEmotion.kt`，那份词表是模型识图和分组名判断共用的）
- 子目录名带上情绪词也认，比如「开心的图」会被认成「开心」
- 直接丢在 `stickers/` 根下的图会进「默认表情」分组。那个组名不是情绪，
  所以组里的图要靠识图分类才能被模型用上——能分子目录就别偷懒
- 支持 `png` / `jpg` / `jpeg` / `webp` / `gif`
- 单张压完不能超过 2MB。png/jpg/webp 会自动缩到长边 512；gif 原样保留（缩放会丢动画），
  所以动图自己控制好体积

## 行为

- 只在首次启动导入一次，靠 DataStore 里的 `builtin_stickers_imported` 标记判断
- 用户之后删掉这些表情**不会**重新冒出来（删了又回来是 bug 不是功能）
- 这个目录空着也没问题，那就等于没有内置表情，功能其余部分照常
- 单张图的标记（label）自动生成，形如「开心1」「开心2」。它只是内部标识，
  模型看不到，用户想改可以在表情页改

不要放微信、QQ、LINE 这类平台的官方表情——那些是有版权的美术资源，打包进 APK 分发有风险。
用自己画的、CC0 授权的，或者明确允许再分发的素材。
