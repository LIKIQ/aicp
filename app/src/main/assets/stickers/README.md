# 内置表情包素材放这里

把表情图片直接丢进这个目录（`app/src/main/assets/stickers/`），首次启动时会自动导入成一个叫
「默认表情」的分组。

## 规则

- 支持 `png` / `jpg` / `jpeg` / `webp` / `gif`
- **文件名就是表情标记**：`开心.png` 会变成聊天里能用的 `[开心]`，所以文件名请用中文短词，
  不要带空格和方括号
- 单张压完不能超过 2MB。png/jpg/webp 会自动缩到长边 512；gif 原样保留（缩放会丢动画），
  所以动图自己控制好体积
- 标记跟已有表情撞名时自动加数字后缀（开心 → 开心2），不会覆盖用户自己导入的

## 行为

- 只在首次启动导入一次，靠 DataStore 里的 `builtin_stickers_imported` 标记判断
- 用户之后删掉这些表情**不会**重新冒出来（删了又回来是 bug 不是功能）
- 这个目录空着也没问题，那就等于没有内置表情，功能其余部分照常

## 版权提醒

不要放微信、QQ、LINE 这类平台的官方表情——那些是有版权的美术资源，打包进 APK 分发有风险。
用自己画的、CC0 授权的，或者明确允许再分发的素材。
